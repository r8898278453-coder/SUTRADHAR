PC maintenance intents — NOT installer approval

—

Owner may record a five-minute advisory intent for an already approved, idle PC. Central checks live Master/Backup 1/2, server-clock heartbeat, active tasks and Master epoch. This does not drain work, stop any agent, reserve a maintenance lease, install software or authorize a rollback.

A started fence never expires automatically. Existing work is not stopped or revoked. Finalize only after Central finds no active work.

Caution: releasing a fence allows new claims and leadership candidacy to resume. Never release while a physical update is underway.

Always recheck the live cluster before physical maintenance. A five-minute intent may expire, but an active drain fence persists until Owner release. Fenced status never authorizes software installation.
